# Development archive

The [development archive](https://github.com/desanv01/Flight-Controller-V1/releases/download/v1-portfolio-publication/Flight-Controller-V1-Development-Archive.zip) preserves unique technical records, CAD snapshot fragments, accepted and failed routing trials, and relevant scripts. [Index](development-index.json) records duplicates and public hashes.

Fragments are historical experiments, not alternative manufacturing releases. The current coherent design is in `hardware/`; vendor-specific designs are in `fabrication/`. Original private workspaces remain preserved locally. No tool runtime, supplier correspondence or private session archive is included.
